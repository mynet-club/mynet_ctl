## 3. 测试节点约定

| 主机 | 用途 |
|---|---|
| `192.168.0.32` | 节点 A（gnb 或 wg） |
| `192.168.0.16` | 节点 B |
| QEMU VM `192.168.101.2` | 节点 C（可作双驱动桥） |
| macOS 本机 | 控制端 + 可选节点 |

**允许**：SSH、装包、写 /etc/mynet、起停服务、改测试网卡  
**禁止**：生产密钥、DNS、GitHub org 设置、生产网段路由/防火墙
