## 关键结论

1. **所有物理网络通过 GNB 节点双向组网互访**（10.182.236.x）。
2. **本机 Mac 通过 WG 网络访问 100.0 网络**（10.66.66.2 ↔ 10.66.66.1）。
3. **GNB 网络统一用 GNB IP 描述**（如 QWRT 旁路由 = 10.182.236.184）。
4. **8.207 是 Intel Mac**（Intel Xeon X5690），可提供 Intel Mac 测试。
5. **公网 IP 只有 .188 是固定的**（18.141.199.14），其他节点公网出口动态。
6. **.180 / .188 在同一子网的 VPS 上**，形成独立物理网络。
