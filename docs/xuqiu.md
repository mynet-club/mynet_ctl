## AI+IP 创作助手小程序 — 需求分析

### 一、产品定位

这是一个面向**个人 IP 创作者**（主要是短视频运营者）的微信小程序，核心是用 AI 辅助完成从 **IP定位 → 选题 → 创作 → 分析** 的完整闭环。

---

### 二、功能模块拆解

#### 1. IP 定位（用户引导流程）

```
首次登录
  ├── 未测试 → 测试问卷 → AI 生成定位分析报告
  ├── 已测试 → 查看报告 / 重新测试
  └── 跳过测试 → 强制填写定位表（不可绕过）
```

**关键数据：** 用户定位表/报告 → 贯穿后续所有功能的**上下文注入**

**开发重点：**
- 问卷引擎（多选/单选/打分题）
- 定位分析 Prompt 设计（输入问卷答案 → 输出结构化 IP 定位标签）
- 定位数据持久化，供其他模块调用

---

#### 2. 今天发什么（核心功能，复杂度最高）

| 子功能 | 输入 | AI 处理 | 输出 |
|--------|------|---------|------|
| 每日热点 | 用户行业标签 | 爬取+筛选热点 | 对口热点列表 |
| 爆款拆解 | 第三方链接（抖音/视频号等） | 解析结构 → 生成新选题 | 选题方案 |
| 灵感创意 | 用户灵感文字 | 提炼+扩展 | 选题大纲 |
| 爆款仿写 | 爆款链接/文案 | 风格改写 | 用户风格文案 |
| 智能创作 | 选题 + 个人知识库 | RAG 创作 | 完整文稿 |

**开发重点：**
- 热点抓取：需要对接第三方热点 API 或爬虫（抖音热榜、微信热点等）
- 链接解析：需要解析视频链接提取文案（敏感，需注意平台限制）
- 智能创作：需要接入用户知识库（RAG，Retrieval-Augmented Generation）

---

#### 3. 内容制作

| 子功能 | 性质 | 建议方案 |
|--------|------|---------|
| 一键剪口播 | 音视频处理 | 接入剪映/必剪 API 或云端视频处理 |
| AI 混剪 | 第三方集成 | 对接现有 SaaS（如 Runway、可灵等）跳转 |
| AI 生成短视频 | 文生视频 | 接入可灵/即梦/Sora API |

**开发重点：**
- 视频生成成本高，需设计使用次数/积分限制
- 混剪建议直接做跳转集成，不做自研

---

#### 4. 数据分析（两个版本）

```
简版（低门槛）:  用户截图上传 → OCR 提取数据 → AI 分析建议
智能版（深度）:  账号 OAuth 授权 → 抓取真实数据 → 深度分析报告
```

**开发重点：**
- 简版：图片 OCR（腾讯云/百度 OCR）+ 数据结构化 Prompt
- 智能版：需要平台开放授权（抖音/视频号 OpenAPI），**申请周期长**，建议独立排期

---

#### 5. 问老师（知识库 RAG）

```
后台：老师知识库（文章/语音/视频文字转录）→ 向量化存储
前端：用户问题 → 语义检索相关知识 → 注入 Prompt → 回答
```

**开发重点：**
- 知识库管理后台（老师端）
- 向量数据库（Pinecone / Weaviate / 自建）
- 答复需体现老师"风格"，Prompt 工程要求高

---

#### 6. 个人中心

- **个人诊断报告**：聚合 IP 定位报告 + 历次数据分析报告，展示为时间线
- **个人知识库**：用户自建 RAG 库，供智能创作调用 → 本质是用户版"问老师"架构

---

### 三、技术架构建议

```
小程序前端（微信）
    ↓
API 网关
    ↓
├── 用户服务（定位/知识库/报告）
├── 内容服务（热点/创作/文稿）
├── AI 调度层（LLM 路由 + Prompt 管理）
│       ├── 通用创作 → GPT-4o / Claude
│       ├── 知识库 RAG → 向量检索 + LLM
│       └── 图像/视频 → 专用模型 API
├── 数据分析服务（OCR + 多平台授权）
└── 爬虫/热点服务（热榜聚合）
```

---

### 四、风险与排期建议

| 风险点 | 等级 | 建议 |
|--------|------|------|
| 第三方平台链接解析（抖音/视频号） | 🔴 高 | 先用用户手动粘贴文案替代链接解析 |
| 账号 OAuth 授权（智能版数据分析） | 🔴 高 | 独立排期，先上简版 |
| 视频生成成本 | 🟡 中 | 限制次数，按会员套餐分级 |
| 知识库 RAG 效果 | 🟡 中 | Prompt 迭代周期长，需内测阶段 |
| 用户定位数据冷启动 | 🟡 中 | 强制填写定位表保障数据完整性（已设计） |

---

### 五、建议 MVP 优先级

**P0（首版必须）：**
- IP 定位问卷 + 报告
- 每日热点 + 智能创作（含知识库）
- 问老师（知识库 RAG）
- 个人中心（报告展示）

**P1（二期）：**
- 爆款拆解 / 灵感创意 / 爆款仿写
- 数据分析简版（截图 OCR）
- 个人知识库自建

**P2（三期）：**
- 内容制作（视频生成）
- 数据分析智能版（OAuth）
