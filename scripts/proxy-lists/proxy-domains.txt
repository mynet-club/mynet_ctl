# 语义：Mac/Win 导航型分流的主清单；也可在 Linux 与 IP 大表叠加

# 叠加：本机 custom_domains 在此之上追加（不回写云端）
# 来源：ctl 发布 → /plugins/mp/proxy-domains.txt
# 更新：2026-10-17 —— 补齐国人常用海外站 + AI 服务主域/辅助域（CDN·鉴权·静态·API）
# 组织：按业务域分组；同站主域与辅助域相邻，便于 diff 与人工审阅
